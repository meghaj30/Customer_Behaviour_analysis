# 📊 Data Analytics Project

## 🔍 Overview

This project demonstrates an end-to-end data analytics workflow — from raw data processing to business insights visualization. It involves data extraction, cleaning, exploratory data analysis (EDA), SQL-based querying, and dashboard creation to derive meaningful insights.

---

## 📁 Dataset

* The dataset contains structured data related to customer behavior.
* Includes features such as demographics, transactions, and activity patterns.
* Used for analyzing trends, patterns, and key business metrics.

---

## 🛠️ Tools & Technologies

* **Python** (Pandas, NumPy, Matplotlib, Seaborn)
* **SQL** (PostgreSQL)
* **Power BI** (Dashboard & visualization)
* **Gamma** (Presentation generation)

---

## ⚙️ Project Workflow

### 1. Data Loading

* Imported dataset into Python environment using Pandas.

### 2. Data Cleaning

* Handled missing values
* Removed duplicates
* Standardized formats and data types

### 3. Exploratory Data Analysis (EDA)

* Univariate and bivariate analysis
* Identified trends, distributions, and correlations
* Visualized insights using plots and charts

### 4. Database Integration

* Loaded cleaned dataset into PostgreSQL database
* Designed structured tables for efficient querying

### 5. SQL Analysis

* Wrote queries to extract business insights
* Performed aggregations, joins, and filtering
* Answered key analytical questions

### 6. Dashboard Creation

* Built an interactive Power BI dashboard
* Visualized KPIs, trends, and comparisons
* Enabled user-friendly data exploration

### 7. Reporting & Presentation

* Created a detailed project report
* Generated a professional presentation using Gamma

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone <your-repo-link>
cd <project-folder>
```

### 2. Install dependencies

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy psycopg2-binary
```

### 3. Run Python scripts / notebook

* Perform EDA and data cleaning

### 4. Setup PostgreSQL

* Create database
* Update connection credentials in the script
* Load dataset into PostgreSQL

### 5. Run SQL queries

* Execute queries using pgAdmin / any SQL client

### 6. Open Power BI Dashboard

* Load `.pbix` file in Power BI Desktop
